The plan says OmniHarness never reads/copies credentials, but also asks it to parse, preserve unknown fields in, and rewrite a provider-owned configuration file. That file could contain credential-bearing or undocumented fields. Remove this write unless it is required by an official, documented Claude Code contract. Prefer letting `claude auth login` finalize its own state. If unavoidable, identify the exact file and schema, prove it contains no credentials, and restrict tests and implementation to an allowlisted mutation that never deserializes or logs secret fields.

- Remote-runner ownership is insufficiently defined. State which machine owns `app-data/account-cli-homes`, the database row, CLI process, terminal buffer, and deletion operation. Define what happens when the selected runner is offline, replaced, or has a new `runnerInstanceId`; central UI/server code must never probe or purge a remote runner’s profile locally. Specify authorization for lookup, input, resize, replay, and cancellation; reject cross-runner and cross-operation terminal access.
